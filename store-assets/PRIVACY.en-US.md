# Privacy disclosure — English

SuperContentExport processes selected webpage content locally in the browser. It stores the latest selection text, CSS selector, and interface language in Chrome's local extension storage so the user can reuse the last selection.

The extension does not send webpage content or settings to a remote server, use analytics, perform OCR, upload files, or sell user data. Markdown and PNG exports stay in the user's normal local download flow. The extension requires webpage access for the user-invoked picker and screenshot fallback; browser-internal and protected pages may remain unavailable.
